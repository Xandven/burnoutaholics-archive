There’s apparently been a printing error with some copies of the game. It seems like some copies are missing  a character from the redemption code. This error has spurred Ubisoft to open the Uplay gates to one and all by making the Passport for this particular game free.

This is good news for me as we have only one copy of the game and several XBox 360s. Both Zombietron and I can now play the game online... for free 🙂
