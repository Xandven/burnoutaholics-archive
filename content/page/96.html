We have collected links to some of the best sources for information about Burnout. This include all the official Burnout websites from EA and Criterion, various community web sites and the information that can be found about burnout on wikipedia.org

If you are running a game related web site and want us to link to your site please send us a link to your site using our feedback form and some information about your site. All we ask in return is that you link to us. 

We have updated some of urls that no longer work to point to the Internet Archive.
