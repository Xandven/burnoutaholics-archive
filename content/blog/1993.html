BurnoutAholics.com has now been upgraded to the latest supported version of Drupal. We are still working on the site but most of the features and a couple of new ones are already up and running. Some content is still missing but I hope to fix that quickly.

We will also be doing some major changes to the apperance of the site but that will have to wait until we are sure everything is ok after the upgrade.

Here is a couple of things that have changed:

Text editor:
- The editor used for writing comments and blogs has been upgraded.

Spam prevention:
- New image captcha on the sign up page

Forums:
- Better navigation

Private messages:
- Number of new message showing in header
- Possible to block senders
- New threaded view (not for old messages) 
- All archives have been cleared due to incompability with new version

Google +1:
- Google +1 integration added. Button is displayed on most content.

Things that got lost:
 - Unfortunately everyone will have to resubmit their Xbox Live Gamertag, PSN id, etc as the existing data got lost in translation... well it was too hard to translate so I let it go :-)
- Twitter account info will need to be reentered in the profile.

Please update your profile now! Add your twitter accounts, Xbox gamertags, PSNids, steam accounts and any other information you want to share.
