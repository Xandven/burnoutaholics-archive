I've noticed that we've had some empty comments since the update last night. This is caused by caching in Internet Explorer or whatever web browser you are using. The first time you post a comment please press CTRL + F5 (in Internet Explorer)  in the page where you type the comment to reload the page from the server. A normal refresh (F5) will not work since it will only reload the page from cache.
