Without further ado, the Vanity Pack 1.0 release is now available for download, adding some vanity to your Burnout Paradise experience.

 

 

 

Be sure to read the disclaimer fully. You'd be wise to make backups of game folder and savegame, just in case. Remember: Backups are your friend. Check out the included README file for the latest information of known issues.

  This unlocks bikes that could not be repaired or painted. If you could not select all country variations of the Nakamura Firehawk GP Competition then you've run into this defect in the original game. This patch unlocks those bikes.
